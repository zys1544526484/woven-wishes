# 版权及开源使用说明

## 代码

作品受 MIT 项目 andHW/lod 的玩法思想启发，固定考察版本为 `7c26fcf0284bb40a2d498bff1e64213a5697c905`。本作采用 TypeScript/React/Canvas 独立重写，无上游源文件、截图、JoJo 资料、r/place 色板或外链字体残留。原 MIT 许可证保存在根目录 `LICENSE`，差异见 `MODIFICATIONS.md`。

## 字体

静态标题使用 Noto Serif CJK SC OFL 1.1 字体子集。原始字体、许可与可复现子集脚本分别位于 `third_party/noto-serif-sc/` 和 `scripts/subset_font.py`。观众自由输入使用系统字体，不嵌入系统字库。

## 视觉与纹样

八个网格纹样由作者按文字资料中的题材概念原创重绘，不复制网页、博物馆或官方素材包图片。背景丝线和梭子由生成式 AI 依照作者已确认的概念图制作并经人工选择；它们不承载历史纹样或文物外观。界面图标为项目内原创 SVG 线条。

## 内容与隐私

文化资料仅作事实考据，页面图像未进入作品。心愿只存在浏览器内存和二维码 URL fragment，不上传、不建立数据库；分享页静态重建纹样。结果卡标注“非真实织造复原”。
