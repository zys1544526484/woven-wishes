# 展项运行说明

1. 将 Windows 显示设为 1920×1080、横屏、缩放 100%，Chrome 更新到稳定版。
2. 断开网络，双击 `index.html`；进入全屏 `F11`。冷启动后应出现输入屏且无浏览器网络错误。
3. 可使用系统触摸键盘输入 2—48 个字素；键盘不可用时点选四个预设之一。
4. 送梭必须从梭子开始，依照当前方向横向滑动至少轨道 70%；每次完成一行，共 24 行。
5. 声音默认在首次确认心愿后启动；三屏右上角均可关闭。声音完全由浏览器本地合成，不加载音乐文件。
6. 结果页二维码指向 `https://zys1544526484.github.io/woven-wishes/share.html`；手机需要联网，主流程、PNG 与二维码生成本身不依赖展项网络。
7. 每日开场前测试中文、英文、短滑回弹、24 梭、保存 PNG、再织一次；确认织造页出现“织手送纬/拽花工提经”，结果页出现“织，不是绣”；保存文件后清理下载目录。

故障兜底：模型权重异常会自动使用通用流云纹样；二维码外链未配置时仍可完成主体验与 PNG，但手机无法访问本地 `file://` 分享页。若界面比例异常，恢复 16:9 和 100% 浏览器缩放。
